# Инструкция по установке:
  ## 1. Установка:
      ```
        https://github.com/mirweryy/log_html.git
      ```
  ## 2. Сборка проекта:
    ### Создайте папку build и введите команды
      ```
        cmake -S . -B build
        cd build 
        make
      ```
      
# Инструкция по использованию:  
  ## Конфигурации:
  В папке config_data лежит файл color.css можно настроить свои цвета для html. Можно менять только значения, наименования параметров не нужно менять.
  Если изменили данные, то нужно заново запустить cmake, либо эти данные можно менять в папке build и тогда не нужно будет заново прописывать cmake.

  ## Как использовать:
    В папке build лежит бинарная программа program, она принимает на вход один параметр (путь к файлу, можно передать относительный и абсолютный путь)
